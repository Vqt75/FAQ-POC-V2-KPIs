# Studio V2 8A — Semantic Rich Text

Les zones narratives éditables autorisent uniquement **gras**, *italique* et soulignement sur sélection. Storm conserve la responsabilité visuelle : aucune couleur, police, taille ou alignement libre.

Champs couverts : introduction et Texte/Focus du Projet, description d’un Espace, présentation du réseau d’Ambassadeurs et message de recrutement.

Les anciens marqueurs `**gras**` sont interprétés visuellement afin qu’ils ne soient plus visibles dans Studio. Au prochain changement, les champs utilisent des marqueurs sémantiques internes imbriquables. Le collage est nettoyé en texte brut.

Raccourcis : Ctrl/Cmd+B, Ctrl/Cmd+I, Ctrl/Cmd+U. La sélection est obligatoire.
