# Studio Ambassadeurs 6A.1

## Refinements

### Save action
`Enregistrer les ambassadeurs` uses the shared Studio V2 domain-save treatment: dark ink surface, white text, same geometry as Project / News / Spaces / Questions.

### Contact semantics
Contact is split into two decisions:
1. **Network level** — can ambassadors be contacted directly at all?
2. **Individual level** — can this ambassador be contacted, and through which channel?

When network contact is disabled, no public contact CTA appears. When enabled, each ambassador can be disabled independently and receives a manually entered email, Teams link, or other safe URL. The public CTA label is generated as `Contacter <prénom>`.

No shared contact destination is required by default. Legacy shared destination fields remain readable for migration only.

### Copy / typography parity
The network configuration surface now mirrors Ivory's public language: **Des relais au plus près du terrain.** The title explicitly uses Italiana in Studio rather than the generic display fallback.
