# Studio Questions 5A.4 — langage Storm Match cohérent

## Principe de langage

Sur la page **Questions**, toute action relevant de la compréhension, du rapprochement ou de la récupération d’une réponse est attribuée à **Storm Match**.

**Storm** reste le nom du produit global.

### Exemples
- `Storm Match reconnaît les différentes façons dont les collaborateurs peuvent poser la même question.`
- `Storm Match les utilise pour retrouver cette réponse.`
- `Storm Match rapproche leurs formulations de la bonne réponse.`

En revanche, les actions globales de produit — enregistrer, publier, administrer l’espace projet — restent attribuées à **Storm**.

## Intention

Installer Storm Match comme une capacité produit identifiable sans multiplier les mentions marketing ni exposer la plomberie du moteur.
