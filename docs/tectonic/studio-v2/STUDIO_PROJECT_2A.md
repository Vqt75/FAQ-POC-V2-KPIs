# Studio V2 — Le projet 2A

Statut : vertical slice métier après Foundation 0A/0B et Identity 1A.

## Ce qui change

- `Le projet` ne route plus vers l’éditeur Planning Pangea.
- Une surface Studio V2 dédiée affiche une structure stable à gauche et l’édition de la section sélectionnée à droite.
- L’introduction est toujours première et ne peut être supprimée.
- Les sections peuvent être ajoutées, retirées et réordonnées.
- `Grandes étapes` édite la collection autoritaire `milestones[]`.
- `Équipe projet` édite la collection autoritaire `team[]`.
- Images et galeries réutilisent le service d’upload existant.
- Enregistrer sauvegarde le draft ; Publier reste une action globale distincte.

## Hors scope 2A

- aucune permission / aucun rôle (Orogeny) ;
- aucun choix de layout ;
- aucune recommandation automatique de sections ;
- aucun nouveau moteur de curation ;
- aucun changement d’édition publique Ivory en dehors de la consommation de `content.project` déjà prévue.
