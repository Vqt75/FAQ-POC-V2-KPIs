# Studio Questions 5A.3 — Storm Match chrome card

## Intention
Le bloc **Storm Match** ne doit plus ressembler à un séparateur ou à un sous-bloc de formulaire.
Il devient une **capacité produit premium**, calme, légèrement distincte des autres cartes Studio.

## Ce qui change
- suppression des filets gris au-dessus / en-dessous ;
- remplacement par une surface autonome ;
- matière visuelle plus froide et perlée ;
- coins généreux ;
- micro-reflet supérieur ;
- bordure fine plus lumineuse ;
- badge `ENGINE` mieux intégré.

## Ce qui ne change pas
- wording ;
- ordre du contenu ;
- position générale dans la page Questions ;
- fonctionnement de Storm Match.

## Wording
- `INTRODUCING`
- `Storm Match`
- badge `ENGINE`
- `Les collaborateurs n’ont pas besoin d’employer les mêmes mots. Storm rapproche leurs formulations de la bonne réponse.`

## Direction visuelle
Le style recherché est :
- premium ;
- calme ;
- légèrement chromé / nacré ;
- jamais tape-à-l’oeil ;
- jamais marketing agressif ;
- jamais “plugin” ou “widget”.

## Notes
Cette brique est pensée pour pouvoir être réutilisée plus tard pour d'autres capacités produit Studio.
