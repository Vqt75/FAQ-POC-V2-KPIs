# Integration guide — Questions 5A.3

## Replace old markup
Supprimez le bloc Storm Match entouré de filets / séparateurs gris.
Insérez à la place le snippet HTML fourni dans `questions_5a3_html_snippet.html`.

## CSS
Chargez `public/studio-v2/storm-match-chrome-card.css` dans le bundle Studio, ou recopiez les règles dans la feuille utilisée par la page Questions.

## Placement
Le bloc doit apparaître :
1. après le hero de la rubrique Questions ;
2. avant la bibliothèque / liste des questions.

## Important
- ne pas conserver d'<hr> ou de bordure grise avant/après ;
- ne pas imbriquer ce bloc dans une autre carte de formulaire ;
- ne pas lui donner la même surface que les cartes d'édition de question.

## QA
Le bloc doit avoir l'air :
- distinct ;
- premium ;
- calme ;
- cohérent avec Ivory Studio.
